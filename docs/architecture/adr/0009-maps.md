# ADR 0009: MapLibre GL JS with OpenFreeMap tiles

- **Status:** Accepted
- **Date:** 2026-10-04

## Context

The frontend shows maps on most screens (routes, pickup points, live driver location) and should match the clean, light style of our mockups, at no cost.

## Options considered

- **MapLibre GL JS + vector tiles:** Free, open source, fully stylable vector maps.
- **Leaflet + raster tiles:** Simpler API; styling fixed by the tile provider.
- **Tile providers:** OpenFreeMap (free, no key), MapTiler (free tier with key), OSM's own servers (not for app traffic).

## Decision

Use **MapLibre GL JS** with **OpenFreeMap** vector tiles. **MapTiler** is the backup.

## Consequences

**Positive**

- Free, with no API keys to manage.
- We control the map style to match the mockups.

**Negative / trade-offs**

- The map component must be loaded client-side only in Next.js.
